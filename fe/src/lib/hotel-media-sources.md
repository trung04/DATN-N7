# Hotel demo photo sources

The local hotel listings are fictional demo data. The hotel and room photos are real accommodation photographs used as illustrations; they do not depict or endorse the listed businesses. The backend stores seeded demo photos in MinIO and uses the same Unsplash image URL only as a fallback. Mock mode loads these photo URLs from Unsplash directly.
